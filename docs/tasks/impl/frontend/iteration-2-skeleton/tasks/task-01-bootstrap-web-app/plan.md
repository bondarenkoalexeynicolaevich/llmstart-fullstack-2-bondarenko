# Задача: Bootstrap web-приложения

## Цель

Создать каталог `web/` с Next.js (App Router), TypeScript, ESLint, Tailwind CSS и pnpm.

## Состав

- `pnpm create next-app` (или эквивалент) в корне монорепозитория.
- `package.json` с скриптами `dev`, `build`, `start`, `lint`.
- Базовый `app/layout.tsx`, `app/page.tsx` — будут заменены/расширены в task-02.

## DoD

- `pnpm install` из `web/` успешен.
- `pnpm run build` проходит (после правок task-02+ при необходимости).
