## Цель

Плавающая кнопка чата на всех основных страницах и панель (drawer/sheet) с placeholder-текстом; без вызовов диалогового API.

## Состав

- Client component: FAB + shadcn Sheet или Dialog.
- Включение в корневой защищённый layout рядом с детьми.

## DoD

- Виджет виден на `/dashboard`, `/leaderboard`, `/chat`.
- Нет `console.log` с текстом сообщений (сообщений пока нет).
