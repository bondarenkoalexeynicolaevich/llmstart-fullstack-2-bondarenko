# Задача 04: Визуальный стиль и сценарий входа (без OAuth)

## Визуальный стиль

**Ориентир:** [tbench.ai](https://www.tbench.ai/) — тёмный «dev dashboard», плотная информация, лёгкое свечение границ.

### Палитра (черновик токенов)

| Токен | Значение | Назначение |
|-------|----------|------------|
| `bg-base` | `#0a0a0f` | Фон приложения |
| `bg-surface` | `#111118` | Панели, sidebar |
| `bg-elevated` | `#1a1a2e` | Карточки, модалки |
| `border-subtle` | `#2a2a3d` | Разделители |
| `accent` | `#6366f1` | Акцент, ссылки, primary кнопки |
| `accent-muted` | `#818cf8` | Hover |
| `text-primary` | `#f4f4f5` | Основной текст |
| `text-secondary` | `#a1a1aa` | Подписи |

### Типографика

- **Заголовки / UI:** sans-serif (системный стек или `Inter`/`Geist`).
- **Метрики, код, таблицы:** моноширинный (`Geist Mono` / `JetBrains Mono`) для KPI и чисел — опционально, не злоупотреблять.

### Сетка и компоненты

- 12-колоночная сетка на широких экранах; на узких — одна колонка + горизонтальный скролл для матрицы/таблиц.
- Карточки: скругление `md`, тонкая граница + лёгкий `box-shadow`/`ring` в акцентном цвете на hover.

## Вход

### Маршрут

- `/login` — форма из одного поля **Telegram username** (без префикса `@`, trim, case-insensitive на сервере).

### Контекст потока

- Обязательное поле **текущий поток** на шаге логина: выпадающий список `flow_id` или одно значение по умолчанию из конфига (`NEXT_PUBLIC_DEFAULT_FLOW_ID` в итерации 2) — зафиксировать в backend: пользователь должен быть `Participant` выбранного потока.
- Ошибка «пользователь не найден в потоке» — стабильный код API `user_not_in_flow`.

### Сессия (KISS, MVP)

**Решение для итераций 2–6:** после `POST /v1/auth/web-session` клиент хранит `access_token` и метаданные (`user_id`, `participant_id`, `flow_id`, `display_name`, `role`) в **`localStorage`** (ключ например `llmstart_web_session`). Заголовок запросов: `Authorization: Bearer <access_token>`.

- **Ограничение:** уязвимость к XSS; для учебного MVP приемлемо. Переход на **httpOnly cookie** — отдельная задача при харденинге.
- **Выход:** кнопка «Выйти» очищает `localStorage` и редирект на `/login`.

### Защита маршрутов

- Layout приложения: если нет сессии — редирект на `/login` (кроме самой `/login`).
