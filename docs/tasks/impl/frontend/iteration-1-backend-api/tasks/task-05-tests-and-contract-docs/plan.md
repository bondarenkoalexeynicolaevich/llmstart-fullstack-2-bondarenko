# Задача 05: Тесты, lint и синхронизация документов контрактов

## Цель

Закрыть итерацию 1 качественно: автотесты покрывают новые маршруты, `make lint-backend` и `make test-backend` зелёные, текстовые контракты совпадают с кодом и OpenAPI.

## Тесты (`backend/tests/`)

- Принести паттерны из существующих тестов (fixtures БД / TestClient / async).
- Минимальный набор:
  - **Auth:** `POST /v1/auth/web-session` — успех при валидных данных seed, `404`/`user_not_found` при несуществующем username.
  - **Teacher-only:** студент запрашивает `dashboard` → `403`.
  - **Ленты:** пагинация; пустые ленты — валидная структура.
  - **Матрица / лидерборд:** структурные invariant’ы размеров.
  - **Диалог веб:** `GET` после `POST`.
- Не логировать содержимое пользовательских сообщений в assert output.

## Lint

- `ruff` / настройки проекта — без отключений «в ноль»; исправить то, что внесено в итерации.
