# Задача 01: Gap-анализ — summary

## Решение по данным для веб-входа

Для резолва `POST /v1/auth/web-session` нужен **уникально сопоставимый Telegram username**. В модель `users` добавлено поле `telegram_username` (nullable); уникальный индекс по `LOWER(telegram_username)` **частичный** (WHERE NOT NULL).

## Артефакты

| Артефакт | Назначение |
|----------|-------------|
| `backend/alembic/versions/20260507160000_005_users_telegram_username.py` | миграция колонки + индекс |
| `backend/models/user.py` | ORM |

## Связка с доменной моделью

Сущности пользователь / участник / поток без противоречий с [`docs/data-model.md`](../../../../../../data-model.md); веб-сессия не вводила новых сущностей, только признак входа пользователя во внешнем контексте.
