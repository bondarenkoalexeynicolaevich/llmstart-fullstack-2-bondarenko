# Итерация 6: Чат в основной области — summary

**Статус:** Done

## Ценность

Страница `/chat` и плавающий виджет делят одно состояние диалога (сообщения, черновик, ошибки): нет расхождения истории при переключении между контурами.

## Реализовано

- **`web/lib/chat-context.tsx`** — `ChatProvider`, `useChatStore`, загрузка/отправка, сессия из `getSession()` при монтировании.
- **`web/components/chat-panel.tsx`** — UI только из контекста.
- **`web/app/(app)/layout.tsx`** — обёртка `ChatProvider`.
- **`web/app/(app)/chat/page.tsx`** — полноценная страница чата.
- **`web/components/app-shell.tsx`** — `main` как flex-колонка с `min-h-0`.
- **`web/components/chat-widget-shell.tsx`** — `<ChatPanel />` без проверки сессии внутри (guard в контексте/панели).

## Ограничения / известное поведение

- Как и в итерации 5: история — один запрос до 50 сообщений с начала (контракт backend).
- «Непрочитанное» в виджете отдельно не ведётся — общий черновик и список сообщений сохраняются при навигации в пределах `(app)` до размонтирования `ChatProvider`.
